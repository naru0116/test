# 機密ファイル争奪戦（別班ボードゲーム）

2〜6人で遊べるオンライン対戦の諜報ボードゲームです。ブラウザだけで動き、**すべて無料のサービス**（GitHub Pages ＋ Firebase の無料プラン）で公開できます。

- **ランダムマッチ**: 人数（2〜6人）を選ぶと、同じ人数を選んだ人と自動でマッチングします。40秒たっても満員にならないときは、2人以上いればその人数で開始します。
- **ルーム対戦**: ルームを作り、ルームID か URL を友達に送って遊びます。
- **1台で遊ぶ**: 1つの端末を順番に回して遊びます（通信は不要です）。

## ルール概要

- 工作員は1人3人（A・B・C）。そのうち**1人だけが本物**で、残り2人は囮です。正体は自分にしか見えません。
- 都市には裏向きの**機密ファイル**が置かれています。中身は本物か偽情報のどちらかです。
- 手番ではカードを1枚引き、**2回**行動します（移動／潜入／置く／渡す／カード）。
- **本物の工作員**が**本物のファイル2つ**を持って自分の拠点に戻ったら勝ちです。
- カードは「尋問・拘束・偽装工作・盗聴・緊急脱出」の5種類です。詳しくはゲーム内の「ルール」を見てください。
- 15ラウンドで決着しない場合は、本物のファイルを最も多く持っている人の勝ちです。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` / `css/style.css` | 画面 |
| `js/game.js` | ルールエンジン（画面や通信に依存しない） |
| `js/online.js` | ランダムマッチ・ルーム・オンライン進行・1台モード |
| `js/db.js` | Firebase とデモ用DBの切り替え |
| `js/main.js` | 画面の操作と描画 |
| `js/firebase-config.js` | **Firebase の設定（ここを書き換える）** |
| `database.rules.json` | Firebase データベースのセキュリティルール |
| `tests/` | ルールエンジンの自動テスト（`npm test`） |

## 公開手順（すべて無料）

### 1. Firebase を設定する（オンライン対戦用・約5分）

Firebase の設定をしなくても**デモモード**で起動できます。ただしデモモードでは、同じブラウザの別タブ同士でしか対戦できません。インターネット越しに対戦するには、次の手順で設定します。

1. https://console.firebase.google.com/ を開き、Google アカウントでログインします。
2. 「プロジェクトを作成」を押し、好きな名前（例: `beppan-game`）で作成します。Google アナリティクスはオフで構いません。料金プランは無料の **Spark** のままにします（クレジットカードは不要です）。
3. 左メニューの「構築」→「**Realtime Database**」→「データベースを作成」を押します。
   - ロケーション: `asia-southeast1`（シンガポール）がおすすめです。
   - セキュリティルール: 「ロックモードで開始」を選びます。
4. 作成したデータベースの「**ルール**」タブを開き、このリポジトリの `database.rules.json` の中身をすべて貼り付けて「公開」を押します。
5. 左上の歯車 →「プロジェクトの設定」→「マイアプリ」でウェブアプリ（`</>` のアイコン）を追加します。Firebase Hosting の設定は不要です。
6. 表示された `firebaseConfig` の値を `js/firebase-config.js` に貼り付けます。

   ```js
   export const firebaseConfig = {
     apiKey: "AIza...",
     authDomain: "beppan-game.firebaseapp.com",
     databaseURL: "https://beppan-game-default-rtdb.asia-southeast1.firebasedatabase.app",
     projectId: "beppan-game",
     appId: "1:...:web:...",
   };
   ```

   `databaseURL` が含まれていることを確認してください。含まれていない場合は、Realtime Database の画面上部に表示されている URL をコピーして追加します。ウェブアプリ用の `apiKey` は公開しても問題ない値です。

### 2. GitHub Pages で公開する

1. GitHub のリポジトリで「Settings」→「Pages」を開きます。
2. 「Build and deployment」の Source で「Deploy from a branch」を選び、公開するブランチと `/ (root)` を選んで保存します。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります。

### 無料プランの目安

Firebase の Spark プランでは、同時接続数が100、保存容量が1GB、ダウンロードが月10GBまで使えます。1ゲームのデータは数十KB程度なので、友達同士や小規模なコミュニティで遊ぶ分には十分です。

## 手元で動かす

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
npm test   # ルールの自動テスト（Node.js 18以上）
```

`index.html` をダブルクリックして直接開くと、ES モジュールが読み込めないため動きません。上のようにローカルサーバー経由で開いてください。

## 注意事項

- サーバーを使わない設計のため、ゲームのデータ（相手の正体など）はブラウザ側に届いています。開発者ツールを使えば中身を見ることができてしまうので、**身内で楽しむ用途**を想定しています。
- 対戦中に通信が切れたプレイヤーは、約25秒後に自動で離脱扱いになります。同じタブで再読み込みした場合は、その時間内であれば対戦に復帰できます。
- このゲームはオリジナル作品です。実在の組織やドラマ作品とは関係ありません。
